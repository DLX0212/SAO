Sistema ETL - Análisis de Opiniones de Clientes Resumen Ejecutivo Sistema ETL desarrollado en .NET 8 que procesa opiniones de clientes desde múltiples fuentes (encuestas, redes sociales, reseñas web) almacenándolas en Oracle Database con análisis de sentimientos automático. Arquitectura del Sistema Componentes Principales

ETLWorkerService • Servicio en segundo plano que ejecuta el pipeline ETL • Configurable para ejecución automática cada 24 horas o manual con --run-once
ETLPipelineService • Orquestador principal que coordina todo el flujo ETL • Procesa cada tipo de archivo CSV secuencialmente
Servicios de Soporte • CsvReaderService: Lectura y parsing de archivos CSV • DatabaseService: Operaciones CRUD contra Oracle Database • DataValidationService: Validación y limpieza de datos • SentimentAnalysisService: Análisis de sentimientos en español Flujo de Trabajo ETL Fase 1: Extracción (Extract)
Lectura de archivos CSV desde carpeta ./data
Parsing automático usando reflexión para mapear columnas a propiedades
Validación inicial de estructura de archivos Fase 2: Transformación (Transform)
Limpieza de datos: o Normalización de texto (caracteres especiales, espacios) o Validación de emails, fechas y rangos numéricos o Manejo de campos opcionales y valores nulos
Enriquecimiento de datos: o Asignación automática de IdFuente según tipo de origen o Timestamps de carga automáticos o Normalización de escalas de puntaje (0-5 → 0-10)
Análisis de Sentimientos: o Clasificación: POSITIVA, NEGATIVA, NEUTRA o Score numérico: -1.0 a 1.0 o Extracción de palabras clave relevantes o Diccionarios de palabras en español Fase 3: Carga (Load)
Inserción secuencial en Oracle Database
Manejo transaccional por lotes
Logging detallado de operaciones en tabla LogETL
Generación automática de OpinionesProcesadas para análisis Modelo de Datos Entidades Principales Clientes • Almacena información básica de usuarios • Email único como identificador natural Productos • Catálogo de productos con categorización • Soporte para precios y descripciones opcionales FuenteDatos • Registro de orígenes de datos (CSV, APIs, Web Scraping) • Trazabilidad completa de procedencia Entidades de Opiniones Encuestas • Opiniones internas estructuradas • Puntaje 1-10 + comentarios libres ComentariosSociales • Menciones en redes sociales • Métricas de engagement (likes, shares) ResenasWeb • Reviews de sitios e-commerce • Calificaciones 0-5 estrellas + texto OpinionesProcesadas • Vista unificada de todas las opiniones • Enriquecida con análisis de sentimientos • Base para reportes y analytics Auditoría y Trazabilidad LogETL • Registro completo de ejecuciones • Estadísticas de éxito/error por proceso • Troubleshooting y monitoreo Configuración Archivos CSV Esperados ./data/ ├── clientes.csv ├── productos.csv
├── encuestas.csv ├── comentarios_sociales.csv └── resenas_web.csv Configuración (appsettings.json) { "ConnectionStrings": { "DefaultConnection": "Data Source=host:1521/XE;User Id=user;Password=pass;" }, "ETL": { "DataFolderPath": "./data", "IntervalHours": 24 } } Ejecución Modo Servicio (Continuo) dotnet run Modo Único (Una vez) dotnet run --run-once Características Técnicas • Tolerancia a fallos: Continúa procesando aunque fallen registros individuales • Logging detallado: Seguimiento completo de operaciones y errores • Validación robusta: Múltiples capas de validación de datos • Escalabilidad: Procesamiento por lotes configurable • Mantenibilidad: Arquitectura modular con inyección de dependencias Vistas y Reportes Pre-construidos VW_ResumenOpinionesPorProducto Métricas consolidadas por producto: total opiniones, promedio satisfacción, distribución sentimientos. VW_TendenciaMensualSatisfaccion Evolución temporal de satisfacción por producto y mes. SP_ObtenerKPISatisfaccion Procedimiento para KPIs generales del sistema.
